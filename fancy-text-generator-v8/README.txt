Fancy Text Generator - 部署与 AdSense 过审说明
================================================

一、文件说明
------------------------------------------------
index.html : 网站全部文件（单文件、纯前端、无后端）
             直接用浏览器打开就能用，离线也能跑。
             内含页面：主页（工具）/ Guide & FAQ /
             About / Privacy Policy / Contact。

二、部署方法（三选一）
------------------------------------------------
1. 最简单：把 index.html 上传到你的网站根目录，
   改名为 index.html，访问域名即可。

2. 子目录部署：上传到如 /tools/fancy-text/ 目录下，
   访问 https://你的域名/tools/fancy-text/ 即可。

3. 免费托管：拖到 Cloudflare Pages / Vercel /
   Netlify / GitHub Pages，直接得到 https 域名。

三、sitemap 与 robots（新增）
------------------------------------------------
包里新增了 sitemap.xml 和 robots.txt，部署时注意：
1. 用编辑器打开这两个文件，把里面的 your-domain.com
   全换成你自己的真实域名（3 处）。
2. 这两个文件必须上传到域名的根目录，
   保证 https://你的域名/sitemap.xml 能直接打开。
3. 去 Google Search Console > 站点地图，
   提交 https://你的域名/sitemap.xml，
   Google 就会来抓取收录。
4. 以后每加一个长尾页面，就在 sitemap.xml 里
   加一段 <url>，把网址和日期换成新的即可。

四、AdSense 过审前必须做的事（重要）
------------------------------------------------
[√] 联系邮箱已统一为 faronhuang@gmail.com（如需更换，
    用编辑器全文搜索替换即可）。
[ ] 1. 绑定自己的域名并开启 HTTPS（AdSense 要求）。
[ ] 2. 网站上线后先放 2-4 周，期间保持可访问，
       让 Google 收录几个页面。
[ ] 3. 再按之前说的思路加 10-20 个长尾样式页
       （如 small-text-generator、cursive-fonts），
       内容越丰富过审率越高。单页站也能过，
       但内容单薄是被拒最常见的原因。
[ ] 4. 提交审核时确保：无占位文字、无"建设中"页面、
       导航链接都能点开、手机端显示正常。
[ ] 5. 拿到广告代码后，粘贴到页面预留的广告位占位处
       （搜索 HTML 中的 "adsense" 即可找到）。

四、日常运营建议
------------------------------------------------
- 标题/描述已按 SEO 写好，不要改动过大。
- 想加新花体样式：在 HTML 里搜索 "styles" 数组，
  按同样格式加一行即可，纯前端改动。
- 备份：改之前先复制一份 index.html。
