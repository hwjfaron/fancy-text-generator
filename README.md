Fancy Text Generator

一、文件说明
------------------------------------------------
index.html : 网站全部文件（单文件、纯前端、无后端）
             直接用浏览器打开就能用，离线也能跑。
             内含页面：主页（工具）/ Guide & FAQ /
             About / Privacy Policy / Contact。

二、部署方法（三选一）
------------------------------------------------
1. 最简单：把 index.html 上传到你的网站根目录，
   改名为 index.html，访问域名即可。

2. 子目录部署：上传到如 /tools/fancy-text/ 目录下，
   访问 https://你的域名/tools/fancy-text/ 即可。

3. 免费托管：拖到 Cloudflare Pages / Vercel /
   Netlify / GitHub Pages，直接得到 https 域名。
